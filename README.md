## 更新のしかた

1. `terms-of-service.md` / `privacy-policy.md` を直し、末尾の**版と制定日**を上げる
2. `main` へ push すると数分で反映される(URL は変わらない)
3. 確定前の文書には冒頭に「準備中(ドラフト)」の注記を置く。確定したら注記と【 】を消す

変更の履歴は git のログが正になる。参加者から同意をいただいた版は、その時点のコミットで特定できる。

## 置いてよいもの

公開してよい文書だけ。アプリの内部資料・運用メモはここに置かない。
